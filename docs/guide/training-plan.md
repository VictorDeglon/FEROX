# Your training plan

## Where the week comes from

Your **days per week** picks a template:

| Days | Shape |
|---|---|
| 2 | Full body ×2 — both days press, because with two sessions there is no room for a day that skips a major group |
| 3 | Full body ×3 |
| 4 | Upper / Lower ×2 |
| 5 | Upper / Lower / Push / Pull / Legs |
| 6 | Push / Pull / Legs ×2 |
| 7 | Push / Pull / Legs ×2 plus a conditioning day |

Then your **season** reshapes it — see [Seasons](seasons.md). A strength block
strips the accessory work off each day and adds sets to what is left. A mass
block adds an extra isolation slot. An aerobic block rebuilds the week as two
lifting days plus runs.

## The one rule the builder will not break

**Every major muscle group is trained two to three times a week, at every day
count, in every season.** Training something once a week is the single most
common reason people stall, and the research on frequency is about as settled as
this field gets.

There is exactly one deliberate exception: the Tempo season drops lifting to
twice a week on purpose, because the running is doing the work and the lifting
is there to hold what you have.

## How exercises are chosen

For each slot in a day, FEROX ranks every movement that matches the pattern and
picks the best fit. In order:

1. **Is it one of this day's muscle groups?**
2. **Has this session already trained that group?** — so a day spreads across
   its focus rather than doubling up
3. **Which group does the template list first?**
4. **Has it already appeared this week?** — so the accessory slots rotate
   instead of prescribing the same triceps pushdown four days running
5. **Is it one this season reaches for?** — a Greek Fire leg day opens on box
   jumps, an Iron Base one opens on a barbell
6. **Is it the best kit you actually have?**

That last one matters more than it sounds. If you have a full gym you should be
given the barbell, not push-ups.

The selection is **stable**: the same week always builds the same sessions, so
you can plan around it. It rotates between days and between weeks, so you are
not doing identical sessions forever.

## Equipment and injuries

Tell FEROX you train with dumbbells only and it will never programme a cable
fly. Tell it your knees are a problem and every exercise that loads the knee is
removed from the pool entirely — not swapped for a lighter version, removed.

If those filters leave a day thin, FEROX backfills it from whatever is still
usable rather than handing you a two-exercise session.

## Readiness

Each day the dashboard asks how you feel, 1–10. This is not data collection; it
changes the session:

| | What changes |
|---|---|
| **Wrecked** (1–2) | Half the volume, 30% off the bar. Showing up is the win |
| **Rough** (3–4) | A set off everything, loads pulled back |
| **Okay** (5–6) | Slightly lighter. Stop a rep or two short |
| **Good** (7–8) | Your normal session |
| **Primed** (9–10) | An extra set on the main lift, and a finisher |

Scaling a session beats skipping one. Somebody who trains at 60% on a bad day
keeps the habit; somebody who opens the app, sees a session they cannot face,
and closes it does not.

## The first four weeks

Week one runs about 15% above your steady state and settles by week four.
Motivation is highest the day you install a training app, and a first session
that feels easy wastes it.
